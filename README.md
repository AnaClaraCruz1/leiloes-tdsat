# LeiloesTDSat

## 📌 Sobre o projeto
O LeiloesTDSat é um sistema de leilões desenvolvido em Java com integração ao banco de dados MySQL.  
O projeto foi criado com o objetivo de aplicar conceitos de desenvolvimento back-end, persistência de dados e versionamento utilizando Git e GitHub.

---

## 🚀 Funcionalidades
- Cadastro de produtos
- Listagem de itens disponíveis
- Gerenciamento de leilões
- Integração com banco de dados MySQL
- Persistência de dados

---

## 🛠 Tecnologias utilizadas
- Java
- MySQL
- Git
- GitHub
- NetBeans

---

## 💻 Como executar o projeto

### Pré-requisitos
- Java JDK instalado
- MySQL instalado
- NetBeans IDE

### Passos
1. Clonar o repositório:
```bash
git clone https://github.com/seuusuario/leiloes-tdsat.git
```

2. Importar o banco de dados MySQL.

3. Abrir o projeto no NetBeans.

4. Executar o projeto.

---
